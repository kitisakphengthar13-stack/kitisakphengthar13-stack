# Kitisak Phetchaiwong

**Computer Vision | Edge AI | Practical Vision Systems**

I approach Computer Vision as a complete engineering ecosystem, not just model training.

A useful vision system should not stop when a model produces predictions. It should continue into data preparation, annotation workflow, inference design, post-processing logic, visualization, structured output, deployment, testing, and real-world decision-making.

---

## My View on Computer Vision

For me, Computer Vision is not only about asking:

```text
What class is this object?
```

A practical vision system should also ask:

```text
How reliable is the prediction?
What should happen after inference?
How should the result be filtered or stabilized?
How should the output be visualized?
How can the result be exported or reused?
How can the system be deployed and tested in real conditions?
```

This is why I focus on the full pipeline, not only the model.

## The Computer Vision Ecosystem I Care About

```text
Input
↓

Model Inference
↓
Post-processing Logic
↓
Visualization
↓
Structured Output
↓
Deployment
↓
System Evaluation
```

Each part matters.

A strong model with weak post-processing can still fail in practice.  
A good prediction without a clear output format is hard to reuse.  
A working demo without deployment awareness is not yet a real system.  
A system without evaluation cannot be improved with confidence.

## Engineering Mindset

I prefer building pipelines over isolated demos.

A practical Computer Vision system should have:

```text
Reliable input handling
+ Clear inference flow
+ Practical post-processing
+ Useful visualization
+ Structured output
+ Deployment awareness
+ Measurable results
```

Good Computer Vision work is not only about making predictions.

It is about turning visual information into reliable decisions that can be inspected, tested, reused, and improved.
