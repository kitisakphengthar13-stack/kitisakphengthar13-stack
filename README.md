# Kitisak Phetchaiwong

**Computer Vision | Edge AI | Practical Vision Systems**

I approach Computer Vision as a complete engineering ecosystem, not just model training.

For me, a useful vision system is not finished when a model produces predictions. It should continue into data preparation, annotation workflow, inference design, post-processing logic, visualization, structured output, deployment, testing, and real-world decision-making.

---

## My Computer Vision Philosophy

I focus on building practical vision systems that can answer more than just:

```text
What class is this object?
```

A real Computer Vision system should also answer:

```text
How reliable is the prediction?
What happens after inference?
How should the result be filtered or stabilized?
How should the output be visualized?
How can the result be exported or used by another system?
How can the system be deployed?
How can the system be tested in real conditions?
```

This is why I care about the full pipeline, not only the model.

---

## Engineering Mindset

I prefer building pipelines over isolated demos.

A practical Computer Vision system should have:

```text
Reliable input handling
+ Clear inference flow
+ Practical post-processing
+ Useful visualization
+ Structured output
+ Deployment awareness
+ Measurable results
```

I value systems that are understandable, testable, and maintainable.

Good Computer Vision work is not only about making predictions.

It is about turning visual information into reliable decisions.

## How I Think About Vision Systems

A Computer Vision system should not stop at this:

```text
Image → Model → Prediction
```

A practical system should look more like this:

```text
Image / Video
↓
Preprocessing
↓
Model Inference
↓
Post-processing
↓
Decision Logic
↓
Visualization
↓
Output Export
↓
Deployment
↓
Evaluation
```

The model is important, but it is only one part of the system.

The real value comes from connecting model output to practical logic that can be inspected, tested, reused, and improved.
